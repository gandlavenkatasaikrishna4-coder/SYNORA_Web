Start a shared sound

Open this page on every phone. One phone hosts and the others join with the code. Tap a button on each phone: browsers need a tap before they can play sound. If a page was refreshed, tap Resume, or type the room code and re-join. Songs already on a phone are kept, so they are not sent again.

Connected devices

    Gold arcs = Wi-Fi, gold bars = mobile data, ? = this browser does not say. Strength comes from the measured round-trip time. Make host gives that device the host role; you become a member like the others. Only a device that has all the songs can be chosen.

    File confirm list

      Songs suggested by other devices wait here: device, song, upload status. The host taps Add to put a song in the list for everyone, or Cancel. A song can be added once it says Uploaded. The suggesting device can cancel its own song.

      Songs

        Songs are sent from the host to every phone before playing, and are cleared when the host closes the room. Keep to a few songs, because each one uses a lot of phone memory. On other devices, this button suggests a song; the host must approve it.

        Speed correction
        -

        Trim moves this phone's sound earlier or later. If this phone sounds late, press Earlier. Auto-calibrate: the host plays with no songs (click track), wait 10 seconds, then tap it on each phone. It measures how late this phone is before the speaker. Speaker and Bluetooth delay still need tuning by ear or by recording. Speed correction is a tiny speed-up or slow-down (at most 0.3%) that keeps the phone locked to the host's timeline.

        Live graph

        Waiting for sound...

        White line = loudness over the last 10 seconds. Numbers = the loudest frequency (Hz). Every phone uses the same time axis, so take screenshots together and compare. This reads the sound inside the browser, before the speaker, so it cannot show speaker delay.
