SYNORA

One Sound. Every Speaker.

Prototype code (Phase 1, web). Tests the timing method only. It does not prove Android or Bluetooth speaker behavior. Nothing here is verified on real devices yet.

Start

Open this page on every phone. One phone hosts, the others join with the code. Tap a button on each phone: browsers need a tap before they can play sound.
